# Multivariate-Analysis-Project

Project based on two datasets:

1) Heptathlon Dataset Analysis: 

- Performed exploratory data analysis and standardisation on athletic performance variables after removing the score variable;
- Conducted Principal Component Analysis (PCA) by computing correlation matrices and eigenvalues to derive standardized principal components and evaluate variable-component correlations;
- Applied hierarchical cluster analysis using distance matrices and tested various linkage methods (single, complete, centroid, and Ward's method) alongside the maximum jump criterion to group athletes.


2) Wine Dataset Analysis:
  
- Conducted exploratory data analysis on quantitative chemical features after separating them from the wine type variable;

- Computed group-wise variance-covariance matrices to construct the within-group and between-group deviance matrices;

- Implemented Fisher's Linear Discriminant Analysis (LDA) to find linear combinations that separate the wine groups, followed by model validation using Leave-One-Out Cross-Validation (LOOCV).
